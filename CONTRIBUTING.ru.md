# Участие в разработке

Канон: [CONTRIBUTING.md](CONTRIBUTING.md) (английский).

Спасибо за патч. S.L.A.M — **альфа**-демон под macOS: маленькие изменения, зелёный `swift test`, без секретов.

## Окружение

- macOS на Apple Silicon, полный Xcode (нужен встроенный модуль `Testing`)
- Swift 6.x (`// swift-tools-version:6.0` в `Package.swift`)
- По желанию: [Ollama](https://ollama.com) для живых прогонов (юнит-тесты сеть стабят)

```bash
swift build
swift test
```

Каждый PR обязан оставлять **`swift build` и `swift test` зелёными**. Режим языка Swift 6, `-strict-concurrency=complete`: разделяемое мутабельное состояние — в `actor` или `Sendable`. Сеть — async `URLSession`. Без busy-loop; блокирующие вызовы не в пути демона (исключение — запуск процессов).

Бюджет простоя — часть спецификации (RAM ≤ 100 МБ, CPU ≲ 1%). Правки сети, SQLite или `Process` не должны молча его раздувать.

## Что брать

- Баги и корректность песочницы / HITL
- Тесты на изменённое поведение
- Документацию на **английском, русском и сербском**, если меняете пользовательский README/SPEC

Пожалуйста, **не**:

- Коммитьте `.env`, токены, дампы Keychain, реальные chat ID
- Добавляйте вторую SPM-зависимость без веской причины (в спеке разрешён только GRDB)
- Расширяйте запись песочницы мимоходом — лимит `WORKING_DIR/tmp` это явный дефолт **альфы**; нужна отдельная дискуссия
